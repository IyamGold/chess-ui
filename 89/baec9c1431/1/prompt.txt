# Deploy to Vercel + Railway for Testing

## Context
Phase 1 (online PvP) works locally. We need to deploy so friends/coworkers can test real PvP on separate machines. Three services need hosting:

- **Frontend** (React/Vite) → **Vercel**
- **Game server** (Express + SQLite + WebSocket, port 3001) → **Railway**
- **Passkey server** (Login.com demo, port 3000) → **Railway** (separate service)

## Problem
All server URLs are hardcoded to `localhost` across 7 files. Need to make them environment-driven so the same code works locally and in production.

## Plan

### Step 1: Create shared config for server URLs
Create `src/config.js` — single source of truth for all server URLs. Uses Vite env vars with localhost fallbacks.

```js
export const GAME_SERVER_URL = import.meta.env.VITE_GAME_SERVER_URL || 'http://localhost:3001';
export const GAME_WS_URL = import.meta.env.VITE_GAME_WS_URL || 'ws://localhost:3001';
export const PASSKEY_SERVER_URL = import.meta.env.VITE_PASSKEY_SERVER_URL || 'http://localhost:3000';
```

### Step 2: Replace hardcoded URLs in 7 files
All import from `src/config.js` instead of defining their own constants:

| File | Replace | With |
|------|---------|------|
| `src/hooks/usePasskeyAuth.js` | `API_BASE = 'http://localhost:3000'` | `PASSKEY_SERVER_URL` |
| `src/hooks/useServerAuth.js` | `SERVER_BASE = 'http://localhost:3001'` | `GAME_SERVER_URL` |
| `src/hooks/useOnlineGame.js` | `SERVER_BASE` + `WS_BASE` | `GAME_SERVER_URL` + `GAME_WS_URL` |
| `src/components/JoinGame.jsx` | `SERVER_BASE = 'http://localhost:3001'` | `GAME_SERVER_URL` |
| `src/components/WaitingRoom.jsx` | `WS_BASE = 'ws://localhost:3001'` | `GAME_WS_URL` |
| `src/App.jsx` | `SERVER_BASE = 'http://localhost:3001'` | `GAME_SERVER_URL` |
| `src/hooks/usePasskeyPublish.js` | Check for hardcoded URL | `PASSKEY_SERVER_URL` |

### Step 3: Make game server CORS configurable
In `server/index.js`, read allowed origins from env var:

```js
const CORS_ORIGINS = process.env.CORS_ORIGINS
  ? process.env.CORS_ORIGINS.split(',')
  : [/^http:\/\/localhost:\d+$/, /^http:\/\/127\.0\.0\.1:\d+$/];
```

### Step 7: SQLite on Railway
Railway filesystems are ephemeral. Two options:

   - `VITE_GAME_SERVER_URL` = Railway game server URL
   - `VITE_GAME_WS_URL` = `wss://chess-server-xxx.up.railway.app` (wss, not ws)
   - `VITE_PASSKEY_SERVER_URL` = Railway passkey server URL
